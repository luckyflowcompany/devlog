## 추가
- 78° 직교 카메라, 지붕 없는 방 6칸 기지 (지휘실·무기고·숙소·의무실·창고·작업실)
- 문 뚫린 벽, 그림자, 방별 가구 자리표시
- 용병 자리표시 2명 — 문을 지나 이웃 방으로 배회
- 카메라 각도 슬라이더 45~90° (확정 후 제거 예정), 드래그 이동, 휠·핀치 확대
- 결정적 난수 mulberry32 (`src/core/rng.ts`)

## 변경
- 엔진 Unity → 웹(TypeScript + Three.js) + Capacitor — 2.5D·UI 위주, APK 143MB → 수 MB 예상
- 아트 CRT 터미널 → 2.5D 탑뷰 (폴아웃 쉘터식 단면 기지를 위에서) — 아이소메트릭은 관제 화면 가독성 낮아 기각
- 리포 구성: 게임 코드 비공개, 개발일지만 공개 허브로 분리

## 시행착오
- 문제: Node.js·GitHub CLI 미설치, Homebrew 도 없음
  - 원인: 기존 작업이 Unity 전용 환경
  - 해결: 공식 바이너리를 `~/.local` 에 설치, 체크섬 확인 (관리자 권한 불필요)
- 문제: 개발 서버가 작업 도중 종료
  - 원인: 백그라운드 실행 시간 제한
  - 해결: 제한을 늘려 재실행
- 문제: 첫 스크린샷이 세로(폰 화면)라 목록 썸네일에서 잘림
  - 원인: 모바일 크기로 촬영
  - 해결: 1600×900 가로로 재촬영, 일지 규격에 "가로 16:9" 규칙 추가
- 문제: 용병 2명이 처음에 한 명으로 보임
  - 원인: 같은 칸에서 출발해 첫 이동 전까지 겹침
  - 보류: 타임라인 재생으로 바뀔 때 함께 정리
- 문제: 번들 540KB 경고
  - 원인: three.js 전체 포함
  - 보류: 기능이 늘면 코드 분할
