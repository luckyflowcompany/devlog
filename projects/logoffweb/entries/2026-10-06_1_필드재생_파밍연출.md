## 추가
- 사전계산 타임라인 코어 (이동·파밍·함정·회복·자기보존·캡슐·철수) — C# 판과 1,800판 지문 비트 단위 일치
- 필드 화면 — 출격하면 타임라인을 재생해 용병 이동, 위험 3단 지대, 순찰 구역, 지나온 길
- 관제 HUD (단계·남은 시간·HP·가방), 무전 로그, 배속 ×1/×10/×30, 귀환 보고
- 아트 시안 3종 전환 버튼 — 황무지 한낮 · 볼트 · 핵겨울 황혼
- CC0 3D 모델 — Quaternius Post Apocalypse·Survival, Kenney Survival·Retro Urban
- 용병 애니메이션 — 이동 Walk, 파밍 Duck, 대기 Idle_Gun, 귀환 Wave
- 지붕 없는 평면 건물 — 방 나누기, 벽 두께, 문·창문, 바닥 마감, 무너진 벽, 폐가 7채
- 상자 개봉 말풍선 — 등급별 게이지, 칸 순차 공개, 가방 정리 표시 (Unity 판 이식)
- 실시간 배낭 칸 + 캡슐 칸, 아이템 3D 아이콘
- 상자 위로 아이템이 떠오르는 3D 연출 — 챙기면 용병에게, 두고 가면 바닥으로
- 중간 철수 지시 — 이동 중이면 즉시 돌아서고, 개봉 중이면 그 상자만 마저 챙김
- 비공개 공유 링크로 폰에서 확인 — 모델까지 HTML 한 장에 포함

## 변경
- 카메라 78° → 65° 고정, 각도 슬라이더 제거 — 60°·70° 비교 후 중간값
- 필드 축척 0.1 → 0.25 m/단위 — 지점 간격 5.5m 로는 건물이 안 들어감, 용병 속도 1.75m/s 로 실제 걷는 속도
- 아이템 이름을 3D 모델에 맞춘 임시 목록으로 — 26종 모델 + 귀중품 4종은 코드로
- 상자를 여는 동안 재생 배속 ×2 제한 — ×10 에서 상자 하나가 0.3초에 끝나 안 보임, 작전 시간은 그대로
- 로그 아이템 줄에서 금액 제거 — 무엇을 챙기고 버렸는지만

## 수정
- 교체가 새 물건 값 전체로 표시되던 문제 — 교체는 차액만 늘어난다
- 기지 용병 2명이 같은 칸에서 겹쳐 출발 — 시작 방을 시드로 분리

## 시행착오
- 문제: 공유 링크 페이지에서 화면이 비어 있음
  - 원인: 그 페이지는 fetch 가 막혀 있어 모델·텍스처를 못 읽음
  - 해결: 모델은 data URI 를 직접 풀어 parse, 텍스처는 createImageBitmap 을 잠시 감춰 img 로 읽음
- 문제: 캐릭터 모델이 0.03배 크기로 보이지 않음
  - 원인: 뼈대에 100배 스케일이 걸린 스킨 모델은 일반 바운딩 박스가 틀림
  - 해결: precise 바운딩 박스로 한 번 재서 모델별로 저장
- 문제: 숨긴 패널이 화면에 겹쳐 보임
  - 원인: CSS display:flex 가 hidden 속성을 덮음
  - 해결: [hidden] { display: none !important }
- 문제: 배속을 올려도 레이드 시계가 덜 흐름
  - 원인: 프레임 간격을 0.1초로 잘라 씀
  - 해결: 레이드 시계는 실제 경과 시간 사용, 자르기는 장식 움직임에만
- 문제: 도착 직후 0.6초 사이의 철수 지시에 상자를 새로 엶
  - 원인: 철수 확인이 이동 직후에만 있었음
  - 해결: 상자를 열기 전에도 확인, 자체 테스트 540판에 추가
- 문제: 헤드리스 크롬 캡처가 검은 화면
  - 원인: 개발 서버에서 모델 로드가 가상 시간 안에 끝나지 않는 것으로 추정
  - 해결: 빌드한 HTML 한 장으로 캡처
- 문제: 용병이 벽을 통과해 건물 한가운데로 들어감
  - 원인: 코어는 지점 좌표만 알고 건물 모양을 모름
  - 보류: 건물 손볼 때 화면 쪽 문 경로 추가
- 문제: 금화를 버리고 구급상자를 챙기는 줄이 나옴
  - 원인: 아이템 이름이 값과 무관하게 id 로 정해짐
  - 보류: 이름을 등급에 맞춰 고르기
- 문제: 페이지 7.1MB, 번들 경고
  - 원인: 모델 54개를 페이지 안에 포함
  - 보류: 안드로이드 빌드에서는 파일로 분리

## 고민
- **카메라 각도** — 사용자: "60°~90° 가 다 비슷해 보인다, 그나마 60·70"
  - AI: 직교 카메라라 각도 차이가 벽 앞면 두께로만 드러남. 벽을 4m 로 높이면 입체감은 늘지만 방 바닥을 가림
  - 결정: 65° 고정 (사용자, A·C 사이)
- **타임라인을 어떻게 보여 줄까** — AI 제안: 기지 안에서 진행 상태만(빠름) / 필드 화면(기획에 가까움)
  - 사용자: "구경하는 게 재미"
  - 결정: 필드 화면
- **그래픽 스타일을 언제 정할까** — AI: 목업으로 몇 판 본 뒤 정하자
  - 사용자: 폴아웃 분위기 → 시안 3종 → "모델링이 너무 가라"
  - AI: 무료 CC0 팩 / 코드 모델링 / Blender 비교, 판단하려면 게임 수준 모델이 필요 → CC0 팩
  - 결정: 세 팩 모두 사용 (사용자)
- **"설계도처럼"의 뜻** — AI: 구조(지붕 없는 평면도)인지 화풍(청사진)인지 질문
  - 결정: 구조 (사용자). AI: 지점 간격 때문에 축척을 2.5배로 키움
- **파밍이 안 보이는 문제** — AI: ×10 에서 상자 하나 0.3초. 배속 자체를 내리면 지루함
  - 결정: 개봉 중에만 ×2 로 제한 (AI 제안)
- **중간 귀환** — 사용자 요청. AI: 사전계산 구조라 "지시 시각을 넣고 다시 시뮬" 로 반영, 지시 전까지 결과가 같아야 화면이 안 튐
  - 결정: 이동 중 즉시 철수, 개봉 중엔 그 상자 마무리. 구조 헬기는 전투가 생긴 뒤로 보류
- **교체 표시** — 사용자: "교체는 돈 버는 게 아니다" → 차액으로 수정 → 사용자: "금액은 필요 없다"
  - 결정: 아이템 이름만 표시
- **밖에서 확인하는 방법** — AI 제안: Vercel / 비공개 공유 링크
  - 결정: 비공개 공유 링크 (사용자)
