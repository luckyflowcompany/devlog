# LuckyFlow Devlog

LuckyFlow 가 만드는 게임들의 개발일지 허브 — https://luckyflowcompany.github.io/devlog/

- 규칙: [DEVLOG_SPEC.md](DEVLOG_SPEC.md) · AI 작업 절차: [AI_RULEBOOK.md](AI_RULEBOOK.md)
- 각 프로젝트 리포의 `devlog/` 가 원본이고, 여기 `projects/` 는 복사본이다

```bash
npm install
npm run publish -- ~/Documents/Git/LogOffWeb   # 프로젝트 일지 가져오기
npm run build                                  # site/ 생성 (main 에 푸시하면 Actions 가 자동 배포)
```
